# Polymarket-Copy-Trading-Bot-Python

Production-hardened Polymarket copy-trading bot with MongoDB persistence, structured JSONL logs, and Rich console output.

## Development

- Python 3.11 or 3.12
- Install dependencies with your preferred tool (`uv`, `pip`, etc.)
- Run tests with `pytest`

## Notes

This repository uses a flat package layout. Packaging metadata must explicitly list the top-level packages to avoid accidental package discovery failures.
